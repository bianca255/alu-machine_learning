# Unsupervised Learning: Clustering

This directory contains NumPy implementations of K-means clustering and
Gaussian Mixture Model algorithms, plus selected scikit-learn and SciPy
implementations.

The modules are numbered in the order of the clustering exercises:

- `0-initialize.py` initializes K-means centroids.
- `1-kmeans.py` and `2-variance.py` implement K-means and its variance.
- `3-optimum.py` evaluates candidate K-means cluster counts.
- `4-initialize.py` through `9-BIC.py` implement GMM initialization, EM,
  and Bayesian Information Criterion selection.
- `10-kmeans.py` through `12-agglomerative.py` provide library-based
  clustering implementations.
