# Unsupervised Learning: Hidden Markov Models

This directory contains NumPy implementations for Markov chains and
Hidden Markov Models.

- `0-markov_chain.py` evaluates a state distribution after transitions.
- `1-regular.py` finds steady-state probabilities for regular chains.
- `2-absorbing.py` detects absorbing Markov chains.
- `3-forward.py` implements the forward algorithm.
- `4-viterbi.py` implements the Viterbi algorithm.
- `5-backward.py` implements the backward algorithm.
- `6-baum_welch.py` trains HMM transition and emission probabilities.
