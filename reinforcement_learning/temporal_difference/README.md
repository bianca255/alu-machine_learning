# Reinforcement Learning: Temporal Difference

This directory contains NumPy implementations of temporal-difference
reinforcement learning algorithms for Gym environments.

- `0-monte_carlo.py` performs every-visit Monte Carlo policy evaluation.
- `1-td_lambtha.py` performs TD(lambda) with eligibility traces.
- `2-sarsa_lambtha.py` performs on-policy SARSA(lambda) control.
