# Reinforcement Learning: Q-learning

This directory contains a tabular Q-learning implementation for FrozenLake.

- `0-load_env.py` loads a FrozenLake environment.
- `1-q_init.py` initializes the Q-table.
- `2-epsilon_greedy.py` selects exploratory or greedy actions.
- `3-q_learning.py` trains the Q-table.
- `4-play.py` runs a greedy episode and displays the environment.
